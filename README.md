# Fake Product Identification By QR Using Blockchain

## Project Overview

Fake Product Identification By QR Using Blockchain is a web-based application designed to identify and prevent counterfeit products in the market.

The system generates a unique QR code for every registered product and securely stores product information. Consumers can scan the QR code to verify the authenticity of products.

---

## Features

- Product Registration
- QR Code Generation
- Product Authentication
- Blockchain-Based Verification
- User Management
- Product Tracking
- Counterfeit Detection

## Installation

1. Install Java JDK 8.
2. Install NetBeans IDE.
3. Install XAMPP.
4. Import `fake.sql` from DB folder into MySQL.
5. Open project in NetBeans.
6. Configure database connection.
7. Run the project on Apache Tomcat.
